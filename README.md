## Features:

15+ unique cards, randomized hands for each match, drag/drop card placement. 

## Getting Started: 

- Install and unpack zip
- Start TripleTriad.exe

## Requirements

Windows OS

## Project Structure

This project follows an MVC (Model-View-Controller) pattern with event-driven UI updates
- **Models** — game data and logic (cards, hands, board state, win conditions)
- **Views** — XAML windows and user controls
- **Controllers** — game flow orchestration, turn handling
